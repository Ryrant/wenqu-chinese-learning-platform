# 文趣 · 华文趣味教学助手

面向海外华文学校的多租户 AI 教学平台首版。当前版本提供学生、教师、家长与机构四个角色工作台，并包含可部署的数据、内容和 AI 接口骨架。

## 已实现

- 学生故事闯关、口语录制反馈、每日进度与个性化学习路径
- 教师 AI 备课、教案审核、班级掌握度与作业管理
- 家长成长报告、能力趋势与家庭学习任务
- 机构内容审核、知识发布管线、模型健康与审计概览
- `/api/v1` 版本化接口、SSE 生成、混合检索、R2 内容上传、提交与反馈
- 18 张 D1 业务表，所有关键业务记录包含 `tenant_id`
- 厂商无关模型网关与失败回退接口

## 本地运行

```bash
npm ci
npm run dev
```

生产构建与测试：

```bash
npm run build
node --test tests/rendered-html.test.mjs
```

## 生产绑定

- `DB`：D1 结构化业务数据
- `CONTENT`：R2 教材、图片、音频与作业文件

数据库迁移位于 `drizzle/`。写接口依赖平台转发的已认证用户邮箱；正式接入学校身份系统时，应将邮箱映射到 `role_memberships`，并在服务端解析用户所属租户与角色。

## AI 服务

`app/lib/model-gateway.ts` 定义了文本生成、Embedding、重排、语音识别、语音合成、发音评分、图像理解和内容安全接口。当前演示提供者返回可重复的教学结果；接入真实供应商时，应通过环境变量配置供应商适配器，并保持网关接口不变。
